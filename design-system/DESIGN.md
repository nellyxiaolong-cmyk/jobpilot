# JobPilot 工作台视觉改版方案

## 改版原则
这是现有产品的视觉改版，保留原有页面结构、信息、状态和操作入口。不改变产品功能、不补造指标或业务数据。以克制、专业、易读的桌面工作台为主，整理布局、留白、字号、对齐、颜色、卡片边界与状态标签。

## 覆盖页面
- **总览**：原有两张核心指标卡、投递阶段进展、近期面试和对应入口。
- **投递管理**：原有新增、筛选、搜索区域、投递表格和空状态。
- **面试日历**：原有添加安排、月份切换、日期选择和当日列表。
- **求职分析**：原有模型配置、分析生成、方向匹配、建议、优势/风险和行动计划区域。

## 按钮与业务逻辑
预览复用 Demo 中四个页面的原始结构、按钮、ID 和状态区。新增投递、编辑、模型配置、分析生成等原始产品处理逻辑仍在 Demo 源码中；视觉预览仅实现页面切换和日历浏览，不会写入数据或发起 API 请求。

## 数据与长内容
评审预览使用无记录状态：统计为 0，阶段、投递、日程和分析显示产品现有空状态，不填入示例公司、数值、面试日期或图表。样式允许公司名和面试详情换行，列表随记录数自然延展；窄屏阶段栏可横向浏览。

## 评审入口
`jobpilot-workspace-preview.html` 是可独立打开的完整工作台评审页，导航和月份切换可交互，业务操作为只读展示。
